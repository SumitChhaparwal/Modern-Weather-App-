# Modern Weather Web Application in JS

## Github Project Link (For others):
https://github.com/SumitChhaparwal/Modern-Weather-App-/

## Features
-**Responsive UI**: This web application has a highly Responsive Modern UI that is compatible with a wide range of devices, including tablets, laptops, and smartphones.
-**Highly Dynamic Interface**: When the user search new location or their current location, the whole UI will automatically update according to the place's weather conditions and global time. 
-**Search Bar with Validation**: The user can search for any location all around the world by using the search bar, which also shows an error nicely when the user enters an invalid location. 
-**Current Location**: The user can target the current location by clicking on the button.
-**Extended Forecast**: Through api customization and server request, the user can clearly see 24 hours and 7 days extended forecast or related weather predictions.
-**Data Backup**: The application uses local storage to maintain the user's data after reload or opening a new tab.
-**Custom Pop**: to show api error or the browser-related queries.
-**Recent Search History**: show search history when the user enters a new search query.

## Technologies Used:
HTML5, CSS3, Tailwind CSS, JavaScript(ES6)
